# MargueritrutenAR
Interactive story experience

Abstract
The aim of this project was to create an application which could enhance the experience of taking a walk along a route in nature. Some sketches and a high-fidelity prototype were created to test the application on the target group which is defined as any group of family and/or friends who would like to experience the Danish nature. After conducting a field study with a test group, it was found that there still needed improvements on the application but the overall feedback on the experience was positive.
